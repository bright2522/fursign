# Product overview

## Promise

Fursign helps a person answer a practical question before buying furniture: “Will it fit in my actual room without blocking the door or the useful path?” The prototype is an interior planning tool, not a game and not a substitute for a professional site measurement.

## Primary journey

Capture → Design → Generate specification → Recommend.

The user creates or opens a project, enters room dimensions, places generic furniture, resolves visible geometry warnings, saves the project, generates measured requirements, and then sees only products that pass hard fit filters. The included demo project starts this journey without setup.

## Included capabilities

- Thai-first landing page, project dashboard, room setup, editor, specification, recommendation, and merchant submission flows.
- Interactive orbit, top, and preview camera presets with pointer/touch drag, zoom, and pan.
- 24 generic assets across eight furniture categories and 30 mock products across multiple categories.
- Real-unit object positions and rotations, selectable object bounds, locking, duplication, deletion, wall snapping, 15°/90° rotation, keyboard shortcuts, and 20-step undo/redo.
- Deterministic object overlap, room-boundary, door-sweep, and configurable walkway warnings.
- Device-local projects, mock merchant products, favorites, comparison selection, and outbound click records.
- Rule-based assistant that explains existing project and geometry data without deciding fit itself.

## Success measure for the prototype

A new participant can open the site, create a room, add and move furniture, intentionally create and resolve a warning, save, generate a specification, open recommendations, click a product, reload, and reopen the saved project without facilitator intervention.
